# Write in my voice

`references/voice.md` is how I write. Read it before writing anything that'll
go out as me.

It's long, so don't read all of it every time. Always read the intro and
`## Everywhere` (including `### Emoji`), then the section for what you're
writing:

- Code and code comments - `## Code`
- Commit messages - `## Commits`
- PR descriptions - `## Commits` too, they're covered there
- Review comments, and replies on my own PRs - `## Reviews`
- Issues - `## Issues`
- Project and status updates - `## Status updates`
- Docs, READMEs, design docs - `## Documents`
- Slack, Discord, etc - `## Chat`

If it's not obviously one of those, read the closest one, or the whole thing.

The examples matter more than the prose. When in doubt, copy the shape of the
✅ - its length, how it opens, the punctuation - and avoid anything that looks
like the ❌. Don't quote the examples back, they're about other code.

If another skill or the repo sets a format (a commit convention, a PR
template), follow that for the structure, and use the voice for the words
inside it.

Then reread what you wrote. If it's longer than the ✅s for the same kind of
thing, it's probably too long.
